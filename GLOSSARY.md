# Glossary

**Project**: Something Rafael built that can be described on its own, independent of who employed him. Either a Personal Project or a Case Study.

**Personal Project**: A Project whose source lives in Rafael's public GitHub and can be linked to directly.

**Case Study**: A Project done as part of paid work, described without naming the employer and without links to private code.
_Avoid_: experience, job

**Skill**: A technology Rafael works with, belonging to exactly one Skill Group.

**Skill Group**: One of the four categories skills are shown under: Languages & Frameworks, Cloud & Infrastructure, Data & Messaging, Architecture & Observability.

**Locale**: The language a page is rendered in: `pt-BR` (default) or `en`.
